# UI 구조 & 와이어프레임

> 현재 앱의 화면 구성을 한눈에 보기 위한 시각적 정리.
> 코드 변경이 아니라 현재 상태의 스냅샷입니다.

## 화면 지도

| 라우트 | 파일 | 핵심 역할 |
|---|---|---|
| 💼 계좌 | `src/screens/AccountScreen.js` | 계좌 탭 전환 + 단일 계좌 편집/리밸런싱 |
| 📊 통합 | `src/screens/ConsolidatedScreen.js` | 전체 계좌 합산 (종목별 ↔ 카테고리 그룹별) |
| (모달) | `src/components/ItemEditorModal.js` | 항목 추가/편집 — 종목/분류/가격/보유/비중 |
| (모달) | `src/components/StockSearchModal.js` | Yahoo Finance 검색 → 종목 선택 |

탐색 진입점: `src/navigation/AppNavigator.js` (Bottom Tabs, 2개)

### 항목 row의 4가지 조건부 분기
| 조건 | 표시 |
|---|---|
| A. `hasPrice` & `ownedShares != null` | `보유 X주 → 목표 Y주` + 색상 delta (`+매수 / 매도 / 목표달성 ✓`) |
| B. `hasPrice` & 보유 미입력 | `권장 매수 N주` + `예상 매수금액 … 부족/초과 …` |
| C. `!hasPrice` & 보유 입력됨 | `보유 X주 — 현재가 정보가 있으면 …` |
| D. 둘 다 없음 | `현재가 정보 없음 — …` |

### 빈 상태
- 계좌 0개: 가운데에 "아직 계좌가 없습니다" + `+ 계좌 추가` 버튼
- 항목 0개: "아직 항목이 없습니다." 카드

## 컴포넌트 트리

```
App.js
└── PortfolioProvider                    src/context/PortfolioContext.js
    │   state · usdToKrw · ready · CRUD actions
    └── NavigationContainer (dark theme)
        └── Bottom Tab Navigator         src/navigation/AppNavigator.js

            │       ├── AccountTabsBar   src/components/AccountTabsBar.js
            │       ├── Account info card    (계좌명 + 총금액 + 통화)
            │       ├── DonutChart       src/components/DonutChart.js
            │       │   + Allocation card    (현재가 새로고침, 환율표시)
            │       ├── Rebalance summary    (권장/추가/잔액)
            │       ├── Items list           (4 branches per row)
            │       ├── ExportButtons    src/components/ExportButtons.js
            │       └── (Modal) ItemEditorModal
            │           └── (Modal) StockSearchModal
            │
            └── "Consolidated" (📊)
                └── ConsolidatedScreen   src/screens/ConsolidatedScreen.js
                    ├── Header + currency toggle
                    ├── View mode toggle      (종목별 ↔ 그룹별)
                    ├── DonutChart + summary  (USD/KRW 표시)
                    ├── Category legend       (그룹 모드 전용)
                    ├── Detail list           (rows / collapsible groups)
                    └── ExportButtons
```

상태와 데이터 흐름:
- `usePortfolio()` 훅이 모든 screen/modal에 동일 store 제공.
- 가격/환율은 `src/services/stockApi.js` (Yahoo v8 chart) → `refreshPrices`에서 갱신.
- 계산은 `src/utils/rebalance.js` (`computeAccountRebalance`) / `src/utils/aggregate.js`
  (`aggregateAcrossAccounts`, `aggregateByCategory`).
- 영속화: `src/utils/storage.js` (포트폴리오 상태 + 환율 별도 키).

## 색·강조 사용 규칙

- **계좌 탭 활성**: 파랑 배경 + 흰 텍스트
- **카테고리 배지**: 5색 (성장=파랑, 배당=초록, 채권=주황, 실물=보라, 현금=회색)
- **delta 라벨**: 매수=파랑, 매도=주황, 달성=초록
- **잔액**: 양수=초록, 음수=빨강
- **비중 합계**: 100%=초록, 아니면 주황
