# App Review — 실기기 화면 녹화 가이드

> Apple Guideline 2.1 Information Needed 응답용 화면 녹화 작성 가이드.
> 시뮬레이터 녹화가 아니라 **실기기(Physical Device) 녹화가 요구된다.**

## 0. 사전 준비

1. **빌드 설치** — TestFlight 또는 EAS preview 빌드를 실기기에 설치.
   ```bash
   eas build --platform ios --profile preview
   ```
   완료 후 EAS 가 알려주는 링크를 iPhone Safari 로 열어 설치.
2. **iOS 화면 기록 활성화**
   - 설정 → 제어 센터 → "화면 기록" 추가 (없으면)
   - 제어 센터 펼침 → 빨간 동그라미 → 3초 카운트다운 → 녹화 시작
3. **방해 금지 모드 ON** — 알림 배너로 녹화가 끊기지 않도록.
4. **샘플 데이터 시연용 준비** — 한국주식 1개(삼성전자) + 해외주식 1개(VOO) +
   현금 1개 가 균형 잡힌 데모를 보여주기에 좋다.

## 1. 시연 시나리오 (60–90초 권장)

```
0:00  앱 런치 → "아직 계좌가 없습니다" 빈 상태
0:05  "+ 탭 추가" → 계좌 이름 "Brokerage A", 총금액 10,000,000 KRW
0:15  "+ 항목 추가" → "검색" → "삼성전자" → 005930.KS 선택
        → 가격·통화 자동 입력 확인
0:30  분류 "성장형", 비중 50, 보유 0 → 저장
0:40  "+ 항목 추가" → "검색" → "VOO" → Vanguard S&P 500 선택
        → 분류 "성장형", 비중 30 → 저장
0:55  "+ 항목 추가" → 직접 입력 "현금" / 분류 "현금형" / 비중 20 → 저장
1:00  도넛 차트 + "비중 합계 100% ✓" + "권장 매수 N주" 카드 확인
1:10  하단 탭으로 "통합" 이동 → 종목별/그룹별 토글 시연
1:25  "6개월 백테스트" 버튼 → 모달 → 보유 / 매주 / 매월 / 매분기 세그먼트
        → 새로고침 버튼 → 닫기
1:40  계좌 탭으로 돌아와 "내보내기 → JSON 공유" 시연 (공유 시트 표시 후 취소)
1:50  녹화 종료 (제어 센터 빨간 동그라미)
```

## 2. 녹화 파일 첨부

iOS 가 `.MOV` 로 사진 앱에 저장합니다.

- AirDrop 또는 iCloud 로 Mac 으로 전송
- App Store Connect → My Apps → 해당 빌드 → **App Review Information**
  → Notes 옆 **Attachments** 슬롯에 업로드 (최대 500MB, .mov 가능)

## 3. 흔한 함정 — 미리 점검

- 첫 실행 시 캐시·시드 데이터가 있으면 "빈 상태" 가 안 보인다.
  녹화 전 **앱 삭제 → 재설치** 한 번 권장.
- 키보드가 화면 절반을 가린 채로 시연하면 흐름이 끊겨 보임 — 입력 후
  바로 다음 화면으로 넘어가도록 키보드 dismiss.
- 녹화 중 시뮬레이터에서 했던 캡처(`screenshots/`)는 같이 첨부할 필요 없음.
  실기기 녹화 한 개로 충분.

## 4. 시뮬레이터 자동 녹화 스크립트?

추가하지 않습니다. Apple 은 명시적으로 **physical device** 를 요구하고,
시뮬레이터 녹화는 거절 사유가 될 수 있습니다. 기존
`scripts/screenshots.sh` 의 정지 캡처(`screenshots/01~03-*.png`)는
App Store 마케팅 스크린샷용으로만 사용합니다.
